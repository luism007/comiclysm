# Comiclysm

Comiclysm is an owner-facing inventory and operations platform for comic book stores.

## Planned Features

- Manage comic titles and individual issues
- Track inventory quantities and shelf locations
- Identify low-stock items
- Manage customer pull-list subscriptions
- Track incoming comic shipments
- Role-based access for owners, managers, and employees

## Planned Technology

- ASP.NET Core Web API
- C#
- Entity Framework Core
- PostgreSQL or SQLite
- React
- TypeScript
- JWT authentication
- Swagger / OpenAPI
- xUnit
